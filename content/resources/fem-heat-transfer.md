### Tutorial Overview
This tutorial guides you through the formulation and implementation of a steady-state 2D heat conduction problem using the Finite Element Method (FEM). The code is structured in MATLAB using bilinear quadrilateral elements.

### Topics Covered
1. **Governing Equations**: Derivation of the weak form of the 2D Laplace heat equation.
2. **Element Formulation**: Bilinear quadrilateral elements (Q4) and shape functions.
3. **Global Assembly**: Local element stiffness matrix assembly into the global system.
4. **Boundary Conditions**: Applying Dirichlet (essential) and Neumann (flux) boundary conditions.
5. **Post-Processing**: Plotting temperature contour grids.
